#  Stardance Personal Portfolio

Welcome to my personal website project, built for the **Hack Club Stardance** hackathon! This website is a space to showcase my student profile, skills, and future coding projects.

##  Live Demo
You can view the live, interactive website here:  
👉 **[https://tony-website.oneapp.dev/]**

##  Features
* **About Me:** A brief introduction to who I am and my journey as a student coder.
* **Skills Dashboard:** A visual breakdown of the programming languages and tools I am learning.
* **Responsive Design:** Optimized to look great on both desktop monitors and mobile phone screens.

##  Built With
This entire project was developed using:
* **HTML:** For the structure and layout of the site.
* **CSS:** For custom styling, animations, and typography.
* **JavaScript:** For interactive elements and dynamic features.
* **OneCompiler:** Used as the primary online environment for writing and testing the code.

##  Hack Club Stardance
This project is part of my submission for Stardance. I am tracking my coding hours, building in public, and shipping this personal site to share with the global Hack Club community.
